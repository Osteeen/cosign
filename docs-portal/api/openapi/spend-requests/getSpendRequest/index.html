Spend requests

Get a spend request

GET
/agent/spend-requests/{spendRequestId}

One of this agent's requests. Poll it while it is PENDING_APPROVAL or PROCESSING (every few seconds is fine).

Authorization

agentToken
AuthorizationBearer <token>

The 15-minute token from POST /agent/token.

In: header

Path Parameters

spendRequestId*string

The id of a spend request this agent created.

Formatuuid

Response Body

application/json

Ask to pay a store POST

Cosign checks the purchase against the slip and answers inside this request: - **Paid** (`status: COMPLETED`) - the rules allowed it and the AI check raised nothing. PayPal captured the total from the store's budget hold; `receipt` is filled in. - **Waiting for the owner** (`status: PENDING_APPROVAL`) - over the owner's approval amount, or flagged by the AI check. The owner is emailed. Poll `GET /agent/spend-requests/{spendRequestId}`; the owner approves the exact cart (then it is paid), declines it, or lets it expire after 24 hours. - **Blocked** (`status: DENIED`) - see `decision.reasons`. Nothing is charged. If PayPal does not answer in time the request stays `PROCESSING`; poll it, and Cosign finishes the capture with the same PayPal request ID, so it is never charged twice.
