Get the agent's allowance

GET
/agent/me

The agent's active permission slip: what is left this period, the limits, the allowed categories, and the stores it can pay right now (only stores whose PayPal budget hold the owner has approved). Call this before planning a purchase. slip is null when the agent has no active slip yet.

Get an access token POST

Send the agent's API key with HTTP Basic auth. The key looks like `key_<24 hex>:cs_<secret>`: the part before the colon is the username, the part after is the password. The owner sees the key once, when the agent is added. Tokens last 15 minutes (`expires_in: 900`). Get a new one when a call returns `401`. A paused or revoked agent cannot get a token.
