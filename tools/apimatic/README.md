# APIMatic tooling for Cosign

Cosign's developer docs portal, SDKs (TypeScript, Python, C#) and Context Plugin are generated by [APIMatic](https://www.apimatic.io) from [`api/openapi.yaml`](../../api/openapi.yaml).

- `portal/src/` - the APIMatic project: `apimatic.json` (branding, plugin identity, languages), `content/` (welcome page), `static/` (logo, favicon) and `spec/` (a copy of the Cosign spec).
- `apimatic.sh` - runs the pinned CLI (`@apimatic/cli` 2.0.0-beta.5) with Node 24 from `.nvmrc`, without changing the machine's default Node.
- `regenerate.sh` - one command: validates the spec, regenerates `docs-portal/` and `sdks/` at the repo root, and the Context Plugin in `build/plugin/`.

Setup once: `nvm install` (Node 24 from `.nvmrc`), `npm install --ignore-scripts` here, then `./apimatic.sh auth login`.
